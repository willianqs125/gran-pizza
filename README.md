## 🚀 Sobre o projeto

O **Gran Pizza** é um projeto demonstrativo desenvolvido para simular a presença digital de uma pizzaria.

A proposta é oferecer uma experiência simples e intuitiva para que o cliente possa visualizar o cardápio, escolher seus produtos, personalizar sabores e realizar um pedido através da interface.

O projeto também conta com uma área administrativa para gerenciamento das informações da aplicação.

---

## ✨ Funcionalidades

* 🍕 Catálogo de pizzas e produtos
* 🧀 Seleção e personalização de sabores
* 🛒 Carrinho de compras
* 📦 Fluxo de pedidos
* 🏪 Opções de entrega e retirada
* 🎟️ Sistema de cupons
* 👨‍💼 Área administrativa
* 📊 Gerenciamento de pedidos
* 📱 Interface responsiva
* 💾 Persistência de dados
* 🎨 Identidade visual personalizada

## 🎯 Objetivo

Este projeto foi desenvolvido para praticar e demonstrar conhecimentos em desenvolvimento web, criação de interfaces responsivas, JavaScript, experiência do usuário e desenvolvimento de sistemas para pequenos negócios.

## 📱 Responsividade

A interface foi desenvolvida para diferentes tamanhos de tela, buscando proporcionar uma boa experiência em computadores, tablets e dispositivos móveis.
